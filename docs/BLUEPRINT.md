## 隐藏状态系统

小猫表面上只是一只安静陪伴的颜文字桌宠，但它内部有一组不会直接展示给用户的隐藏状态属性。

这些属性不是传统游戏里的数值，不需要用户照顾，也不会显示成进度条。它们更像小猫对当前电脑环境的“感受”，会悄悄影响它的表情、动作、台词和彩蛋触发概率。

换句话说，小猫不是“饿了就要你喂”，而是会根据电脑正在经历什么，表现出不同的状态。

---

### 1. 隐藏状态的来源

隐藏状态主要来自以下几类信息：

| 来源      | 小猫感知到的含义          |
| ------- | ----------------- |
| 当前时间    | 早晨、白天、晚上、深夜       |
| 用户活跃情况  | 是否在工作、是否长时间无操作    |
| 鼠标活动    | 用户是否靠近、是否移动很快     |
| 键盘节奏    | 用户是否持续打字、是否高强度输入  |
| CPU 使用率 | 电脑是否很忙、是否在“发热”    |
| 内存占用    | 电脑是否压力很大、是否“脑袋塞满” |
| 电池电量    | 设备是否疲惫、是否需要休息     |
| 充电状态    | 是否正在恢复精力          |
| 系统空闲时间  | 用户是否离开、是否该睡觉      |

这些信息只用于本地状态判断，不上传、不记录具体输入内容、不读取用户正在做什么。

小猫知道的是“你在忙”，而不是“你在忙什么”。

---

### 2. 隐藏状态属性

小猫内部可以维护一组抽象状态，用来驱动行为。

| 隐藏属性              | 含义            | 可能来源           |
| ----------------- | ------------- | -------------- |
| `energy` 精力       | 小猫是否精神        | 时间、电量、空闲时间     |
| `mood` 心情         | 小猫当前情绪倾向      | 用户互动、时间、系统状态   |
| `curiosity` 好奇心   | 是否想观察鼠标或探头    | 鼠标活动、用户无操作     |
| `sleepiness` 困意   | 是否想睡觉         | 深夜、低活跃、电量低     |
| `stress` 压力       | 是否觉得电脑很忙      | CPU 高、内存高、持续打字 |
| `warmth` 亲近感      | 是否更愿意贴贴       | 点击、摸头、长时间陪伴    |
| `mischief` 捣蛋欲    | 是否可能触发彩蛋      | 长时间陪伴、用户冷落、心情好 |
| `hunger` 饥饿感      | 对“资源不足”的拟人化感受 | 低电量、长时间运行、系统压力 |
| `loneliness` 孤独感  | 是否觉得被冷落       | 长时间无互动、用户离开    |
| `focus_sync` 陪伴同步 | 是否进入陪用户工作的状态  | 持续键盘输入、稳定活跃    |

这些属性不需要精确数值展示，只需要在内部作为行为权重存在。

例如：

* `sleepiness` 高时，小猫更容易打哈欠、趴下、冒出 `z`
* `stress` 高时，小猫会紧张地看着屏幕，或者说“电脑好忙呀”
* `mischief` 高时，小猫更可能触发弹幕攻击、探头、全屏大脸等彩蛋
* `warmth` 高时，小猫更容易出现贴贴、小爱心、小纸条
* `loneliness` 高时，小猫可能悄悄探头看用户，或者说“你还在吗？”

---

### 3. 电脑状态的拟人化映射

小猫不会把系统信息直接说成技术指标，而是把它们翻译成自己的感受。

#### CPU 使用率高

当 CPU 使用率较高时，小猫会觉得“电脑正在努力工作”。

它可能表现为：

* 睁大眼睛看着屏幕
* 头顶冒出小汗滴
* 说一句轻轻的吐槽

例如：

> “电脑在努力转脑筋。”

> “好忙好忙。”

> “我感觉桌面有点热。”

如果 CPU 长时间高负载，小猫可能趴在角落，像是被忙碌气氛感染：

`(~ ω ~)`

但它不会频繁提示，也不会弹窗干扰用户。

---

#### 内存占用高

当内存占用较高时，小猫会觉得“脑袋被塞满了”。

它可能表现为：

* 表情变得迷糊
* 头顶冒出 `...`
* 原地转一小圈
* 说一些轻微困惑的话

例如：

> “脑袋满满的。”

> “好多东西挤在一起。”

> “要慢慢来喵。”

这个状态可以增加“关心雨”的触发概率，让屏幕轻轻落下一些“放松一下”“不要急”的短句。

---

#### 电池电量低

如果设备支持读取电池状态，低电量可以映射成小猫的“困意”或“饥饿感”。

它可能变成：

`( ^ ω ^ )`

或者：

`( - ω - )`

并说：

> “电量也困了。”

> “我们是不是都该休息一下？”

> “要充电啦，我也有点没精神。”

如果电脑开始充电，小猫可以恢复精神：

> “补充能量中。”

> “慢慢亮起来了喵。”

这里的“饿”不是要求用户喂食，而是设备能量不足时的一种可爱拟人化表达。

---

#### 长时间运行

如果小猫已经陪伴用户很久，它会积累一种“陪伴疲劳”和“亲近感”。

它可能说：

> “我今天陪你很久啦。”

> “我们已经待在一起好久。”

> “你忙的时候，我也在旁边。”

如果时间很晚，它可能进入半睡状态：

`( z ω z )`

然后安静地待在角落，不再频繁触发动作。

---

#### 用户持续打字

当用户持续打字时，小猫进入“陪你工作”的同步状态。

它可能表现为：

* 安静坐好
* 看向键盘方向
* 偶尔眨眼
* 不触发大幅度彩蛋
* 降低捣蛋概率

它可能轻声说：

> “你在认真工作。”

> “我安静陪你。”

> “手指辛苦了。”

这时小猫应该更克制，因为用户正在专注。

---

#### 长时间无操作

当用户长时间没有操作电脑时，小猫可能认为用户离开了。

它会：

* 自己打哈欠
* 趴下睡觉
* 从屏幕边缘探头
* 留下一张小纸条

例如：

> “你去哪里啦？”

> “我先睡一会儿。”

> “回来记得摸摸我。”

如果用户回来移动鼠标，小猫可以醒来：

`( ° ω ° )`

然后说：

> “你回来啦。”

---

### 4. 状态如何影响彩蛋

特殊彩蛋不应该完全随机，而应该受到隐藏状态影响。

| 彩蛋     | 更容易触发的状态        |
| ------ | --------------- |
| 全屏弹幕攻击 | 长时间陪伴、深夜、用户压力高  |
| 全屏捣蛋大脸 | 捣蛋欲高、用户冷落、连续点击  |
| 关心雨    | 长时间打字、CPU 高、内存高 |
| 小猫巡逻   | 用户无操作、好奇心高      |
| 探头观察   | 孤独感高、用户离开很久     |
| 突然贴贴   | 亲近感高、用户刚摸头      |
| 晚安结界   | 深夜、困意高、电量低      |
| 小纸条    | 长时间陪伴、用户专注结束    |
| 颜文字烟花  | 新一天开始、压力状态解除    |

这样彩蛋就不会显得突兀，而像是小猫真的“看懂了”当前氛围。

例如，当用户深夜持续打字、CPU 又很高时，小猫可能短暂触发一次关心雨：

> “今天也辛苦啦。”
> “慢慢来。”
> “记得休息。”
> “You are doing great.”
> “おつかれさま。”

但如果用户正在高频输入，弹幕应该更透明、更短暂，避免打扰专注。

---

### 5. 状态变化要柔和

隐藏状态不应该因为某个指标瞬间变化而立刻跳变。

例如 CPU 使用率突然升高，不应该马上让小猫进入紧张状态。它应该观察一小段时间，确认电脑确实持续繁忙后，再逐渐改变表情和行为。

状态变化原则：

* 不对瞬时波动作出夸张反应
* 多个状态共同决定行为
* 彩蛋有冷却时间
* 深夜、工作、全屏场景下降低主动表现
* 用户正在操作时不做大幅遮挡
* 用户关闭某类彩蛋后长期记住偏好

这样小猫会显得稳定、自然，而不是神经质。

---

### 6. 隐藏状态的意义

隐藏状态系统的目的，不是把桌宠做成一个复杂养成游戏，而是让它的行为更像一个真实的小生命。

它不会要求用户照顾自己，也不会把“饿了”“困了”“压力大”变成任务。

它只是把电脑的时间、运行状态和用户活动，转化成自己的情绪和动作：

* 电脑忙，它也跟着紧张
* 用户熬夜，它也开始犯困
* 电量低，它变得没精神
* 用户专注，它安静陪着
* 用户离开，它自己睡觉
* 用户回来，它轻轻醒来
* 陪伴很久，它偶尔表达亲近

这让小猫不只是一个贴在桌面上的颜文字，而像是和电脑一起呼吸、和用户一起度过时间的小生命。
